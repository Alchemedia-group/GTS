# GTS – Glazing Trade Supplies website

Static site (HTML/CSS/JS, no build step). Open `index.html` or serve the folder (`python3 -m http.server`).

- `assets/products.js` – placeholder catalogue; edit to add real products.
- Forms (`trade-account.html`, `contact.html`) have no backend yet: set `data-endpoint` on the `<form>` to a service such as Formspree.
- All brand name, contact details, hours and products are placeholders to replace.
